# Projet-Gestion-des-Stagiaires
Plateforme de Gestion des Stagiaires

Ce projet est une application web permettant la gestion complète des stagiaires au sein d’une entreprise ou d’un établissement de formation.
Elle vise à centraliser les informations, simplifier le suivi des stages et améliorer la communication entre les différents acteurs.

Objectifs

Gérer les informations des stagiaires, encadrants et administrateurs.

Suivre le déroulement et l’évaluation des stages.

Faciliter la planification et la supervision des affectations.

Automatiser la génération des rapports et bilans de stage.

Fonctionnalités principales

Gestion des comptes utilisateurs (stagiaire, encadrant, administrateur).

Enregistrement et suivi des stages (dates, entreprise, tuteur, etc.).

Système d’évaluation et de notation des stagiaires.

Génération de rapports ou fiches de suivi.

Tableau de bord récapitulatif.

Technologies utilisées

Langage serveur : PHP

Base de données : MySQL

Front-end : HTML, CSS, JavaScript

Serveur web : Apache

Architecture : MVC (Modèle – Vue – Contrôleur)

Public cible

Responsables RH ou administratifs

Encadrants pédagogiques

Stagiaires

Bénéfices

Centralisation des informations et meilleure organisation.

Gain de temps dans la gestion et le suivi des stages.

Interface simple, intuitive et accessible depuis un navigateur web.
